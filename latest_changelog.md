# Reclaimed 1.3.2

## Additions
- Support for Minecraft 26.3.

## General Changes
- Fixed Morphling being unobtainable using the Essence Cage.

## Aspect Changes
### Morphling
- Focus Ability Void Dash now resets player's momentum when used, allowing more controlled mid-air dashes.
### Voidborne
- Now has -20% Max Health.

## Technical Changes
- Increased Pack Format to `9`.
- Required `aspects` version is now `v1.4.1`
